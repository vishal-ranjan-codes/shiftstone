# _config — Stable References (ICM Layer 3)

The workspace's **stable reference layer**: conventions, style systems and
constraints that stay constant across every run and are editable without
touching code (amendment C3).

- Read these files *before* deviating from house style.
- Reference them from stage contracts as
  `- Layer 3 (Reference): _config/<file>.md`.
- Keep them short and current — they are constraints, not tutorials.

| File | Purpose |
|---|---|
| [conventions.md](./conventions.md) | Naming, commits, file placement, docs discipline |
| [style-system.md](./style-system.md) | Design-token and UI style constraints |
| [constraints.md](./constraints.md) | Hard workspace constraints and budgets |

# Typography Pairings & Modular Fluid Scales

Typographic systems calibrated for high digital legibility, rhythm, and visual hierarchy.

---

## Modular Scale Ratios

| Name | Ratio | Best Suited For |
|---|---|---|
| **Minor Third** | $1 : 1.200$ | High-density enterprise dashboards, table-heavy interfaces |
| **Major Third** | $1 : 1.250$ | Balanced SaaS applications, developer portals, docs |
| **Perfect Fourth** | $1 : 1.333$ | Editorial applications, marketing landing pages, blogs |

---

## Standard Type Step Reference (Base 16px / Major Third 1.250)

- `xs`: `10.24px` (`0.64rem`) — Captions, status badges, tiny microcopy
- `sm`: `12.80px` (`0.80rem`) — Secondary UI labels, table row data, hints
- `base`: `16.00px` (`1.00rem`) — Standard body text, form inputs, button labels
- `lg`: `20.00px` (`1.25rem`) — Subheadings, card titles, prominent alerts
- `xl`: `25.00px` (`1.56rem`) — Section headings (H3)
- `2xl`: `31.25px` (`1.95rem`) — Chapter / Page titles (H2)
- `3xl`: `39.06px` (`2.44rem`) — Hero headings (H1)
- `4xl`: `48.83px` (`3.05rem`) — Display impact headers

## Recommended Font Pairings

### Pairing 1: Modernist Tech (Inter + JetBrains Mono)
- **Headings & UI:** `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
- **Body:** `Inter, sans-serif`
- **Monospace:** `"JetBrains Mono", "SF Mono", Menlo, Consolas, monospace`
- **Qualities:** World-class legibility, neutral geometry, unmatched tabular numeral support.

### Pairing 2: Approachable Humanist (Geist + Fira Code)
- **Headings & UI:** `"Geist", -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`
- **Body:** `"Geist", sans-serif`
- **Monospace:** `"Fira Code", monospace`
- **Qualities:** Crisp letterforms, open apertures, contemporary developer elegance.

### Pairing 3: High-Contrast Editorial (Plus Jakarta Sans + Merriweather)
- **Headings:** `"Plus Jakarta Sans", sans-serif`
- **Editorial Copy:** `Merriweather, Georgia, serif`
- **UI & Code:** `Inter, "JetBrains Mono", monospace`
- **Qualities:** Warm, authoritative, narrative depth for thought-leadership products.

# ss-brand-naming — Strategic Brand Naming Engine

Generates category-defining, collision-free brand names for startups, applications, and core libraries using David Placek's Lexicon Branding methodology.

## Invocation
- Standalone command: `/ss-brand-naming`
- Initializer hook: Invoked automatically at Gate 4.5 in `/ss-init` when project name is undecided.

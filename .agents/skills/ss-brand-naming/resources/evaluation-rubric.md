# Brand Naming Evaluation Rubric & Polarization Index

Strategic stress-testing methodology to select category-defining brand names.

## The Polarization Principle
- **Unanimous early consensus is a warning sign.** Safe names blend into category wallpaper.
- **Polarization is strength.** A breakthrough name often divides a room initially because it reframes category assumptions.

## Stress-Testing Dimensions

1. **The Cocktail Party Test (Phonetic Clarity):**
   - Can a person hear the name once in a noisy environment and spell it accurately?
   - Is there ambiguous spelling (e.g. `c` vs `k`, silent letters)?

2. **UI Cadence & App Icon Legibility:**
   - Does the initial letter make a striking, recognizable app icon or favicon?
   - Is the wordmark balanced when set in standard sans-serif typography?

3. **Verb Potential:**
   - Can the brand comfortably become a transitive verb? (e.g., "to Vercel an app", "to Slack someone").

4. **Negative Connotation Screen:**
   - Check translations across major global languages (Spanish, French, Mandarin, German, Japanese) to ensure no accidental vulgarity or cultural offense.

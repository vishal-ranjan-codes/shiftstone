
# Web Interface Guidelines

Review files for compliance with Web Interface Guidelines.

## How It Works

1. Read the specified UI component or route files.
2. Check against all rules in the guidelines:
   - Touch targets (minimum 44x44px for touch interactions)
   - Proper contrast ratios between foreground and background tokens
   - Keyboard focus rings and ARIA labels on icon buttons
   - Clean transitions and reduced motion fallbacks
3. Output findings in a concise `file:line` format with specific recommended code fixes.

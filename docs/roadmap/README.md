# docs/roadmap/

| Field | Declaration |
|---|---|
| **Purpose** | Long-form development roadmap: milestones, PRDs, OKRs, quarterly themes. Higher-level than the backlog. |
| **When populated** | When the developer begins planning beyond the immediate backlog. Stays empty in a starter project. |
| **File types** | Markdown roadmap files + milestone summaries (OKF frontmatter: `type`, `timestamp`). |
| **Owner** | Developer. |
| **Lifecycle** | Updated quarterly or per release. |

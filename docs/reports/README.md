# docs/reports/

| Field | Declaration |
|---|---|
| **Purpose** | Publication-grade output directory — the "papers" folder. Reports produced by the AI agent or by audits: AI audits, research summaries, performance reports, security audits, ad-hoc investigations the developer asks for. |
| **When populated** | On demand by `/research`, `/bug-report`, or any developer request to "write a report." Stays empty in a starter project. |
| **File types** | Markdown report files + diagrams (OKF frontmatter). |
| **Owner** | AI agent (per command) or auditor. |
| **Lifecycle** | Created → reviewed → archived. |

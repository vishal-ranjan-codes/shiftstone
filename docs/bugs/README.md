# docs/bugs/

| Field | Declaration |
|---|---|
| **Purpose** | Known bugs in the project — a permanent project ledger. **Never delete this directory.** |
| **When populated** | On first bug report (via `/ss-bug-report`); grows over the project lifetime. Stays empty in a starter project. |
| **File types** | Markdown bug files + `open-bugs.md` index (OKF frontmatter: `type: Bug`, `timestamp`, status). |
| **Owner** | Developer + AI. |
| **Lifecycle** | Living ledger; bugs move from open → resolved (resolved entries retained, never deleted). |

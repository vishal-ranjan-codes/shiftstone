# docs/status-reports/

| Field | Declaration |
|---|---|
| **Purpose** | Current development status snapshots — "where is the project right now?" |
| **When populated** | Created/refreshed by `/ss-status` (manual or scheduled). Stays empty in a starter project. |
| **File types** | Markdown status files with timestamp in filename. |
| **Owner** | `/ss-status` skill. |
| **Lifecycle** | Regenerated; old versions archived. |
